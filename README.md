# Веб-приложение магазина
Простое веб-приложение на Python, которое возвращает HTML-страницы.
## 🚀 Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/AnastasyaGeyer1788/Task_assembly.git
cd project

# Запустите сервер
python app.py

# Откройте в браузере
http://localhost:8080
```
### ⚙️ Функциональность
* Веб-сервер на Python с обработкой GET-запросов
* Интерфейс с боковым меню
* Страница контактов с формой обратной связи
* Адаптивный дизайн с Bootstrap 5
* Русская локализация с поддержкой UTF-8

### 🛠 Технологии
* Backend: Python 3, http.server
* Frontend: HTML5, Bootstrap 5, CSS3

### ⚠️Учебный проект
Это приложение создано в образовательных целях для демонстрации работы веб-сервера на Python.
